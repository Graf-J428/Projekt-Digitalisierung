# Anforderungen

Module des Portals laut Aufgabenstellung. Die Spalte „Seite“ verweist auf den Ordner im Prototyp.

| Modul | Funktionen | Seite |
|---|---|---|
| Mitarbeiterverzeichnis | Suchen, filtern, Kontaktdaten und Anwesenheit anzeigen | [03](../portal/03-mitarbeiterverzeichnis/) |
| Urlaubsplan | Teamkalender, Resturlaub, Überschneidungen erkennen | [04](../portal/04-urlaubsplan/) |
| Abwesenheitsmanagement inkl. Genehmigungsworkflow | Urlaub, Home-Office, Fortbildung, Dienstreise beantragen; Status verfolgen | [05](../portal/05-abwesenheiten/) |
| Zeiterfassung | Arbeitszeiten anzeigen, Arbeitszeitänderungen beantragen, Auswertung als PDF exportieren | [06](../portal/06-zeiterfassung/) |
| Employee Self Service | Stammdaten, Anschrift, Bankverbindung ändern; Bildungsurlaub beantragen | [07](../portal/07-meine-daten-ess/) |
| Manager Self Service | Zeitkorrekturen, Urlaubs- und Home-Office-Anträge genehmigen oder ablehnen | [08](../portal/08-genehmigungen-mss/) |
| Chatbot | Assistent, der beim Ausfüllen von Anträgen hilft | [09](../portal/09-assistent-chatbot/) |
| Leistungsbeurteilungen | Ziele und Kompetenzen selbst einschätzen, Beurteilungsgespräch vorbereiten | [10](../portal/10-leistungsbeurteilungen/) |
| Reisekostenverwaltung | Dienstreisen beantragen, Belege erfassen, Erstattung verfolgen | [11](../portal/11-reisekosten/) |

Dazu kommen [Login](../portal/01-login/) und [Startseite](../portal/02-startseite/).

## Nicht-funktionale Anforderungen

- Barrierefreiheit nach WCAG 2.1, Stufe AA (siehe [Styleguide](04-styleguide.md))
- Rollen: Beschäftigte, Führungskräfte, Personalabteilung
- [weitere, z. B. Datenschutz, Protokollierung, unterstützte Browser]
