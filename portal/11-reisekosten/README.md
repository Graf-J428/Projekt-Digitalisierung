# 11 – Reisekosten

Dienstreisen beantragen und abrechnen.

![Reisekosten (Desktop)@1x](mockup/Reisekosten%20%28Desktop%29%401x.png)

## Funktionen

- Kennzahlen: offene Abrechnungen, abzurechnender Betrag, Erstattungen im Jahr
- Ablauf: Beantragt → Genehmigt → Belege erfassen → Prüfung Reisekostenstelle → Erstattung
- Kostenliste (Fahrt, Übernachtung, Tagegeld, Nebenkosten, Gebühren) mit Belegstatus
- Einreichen erst möglich, wenn alle Belege vorliegen
- Übersicht aller Dienstreisen des Jahres

## Offen

- Sätze für Tagegeld laut Landesreisekostengesetz Sachsen-Anhalt prüfen
- Anbindung an das SAP-Reisemanagement klären
