# Gemeinsamer Code

Alles, was auf mehreren Seiten gleich ist, liegt hier und wird von den Seiten eingebunden.

- `css/` – Design-Tokens aus dem [Styleguide](../../docs/04-styleguide.md) als CSS-Variablen, z. B. `--color-primary: #0A6ED1;`
- `components/` – Kopfzeile, Seitennavigation, Buttons, Eingabefelder, Meldungen

Änderungen hier wirken auf alle Seiten.
