# 07 – Meine Daten (Employee Self Service)

Eigene Stammdaten einsehen und Änderungen beantragen.

![Meine Daten (Desktop)@1x](mockup/Meine%20Daten%20%28Desktop%29%401x.png)

## Funktionen

- Profilkopf: Personalnummer, Eintritt, Führungskraft
- Reiter „Persönliche Daten“, „Anschrift“, „Bankverbindung“, „Bildungsurlaub“
- Änderungen an Stammdaten und Anschrift werden von der Personalabteilung geprüft
- Bankverbindung: neue IBAN, Gültig ab, erneute Bestätigung zur Sicherheit
- Bildungsurlaub: Veranstaltung, Veranstalter, Anerkennungsnummer, Zeitraum, Nachweise

## Verknüpfungen

- 0002 (Daten zur Person), 0006 (Anschriften), 0009 (Bankverbindung)
