# 02 – Startseite

Erste Seite nach dem Login, aufgebaut wie ein SAP Fiori Launchpad: zuerst „Was muss ich tun?“, dann „Wo finde ich was?“.

## Funktionen

- Begrüßung und Suche über das ganze Portal
- „Ihre Aufgaben“: offene Punkte nach Dringlichkeit, jeweils mit Link zur Seite
- „Team diese Woche“: wer abwesend ist
- Kacheln für alle Module mit der jeweils wichtigsten Kennzahl (Resturlaub, Gleitzeit, offener Betrag …)

## Benötigte SAP-HCM-Daten

- Kennzahlen aus 2006 (Resturlaub), 2011 (Gleitzeit), 2001 (Abwesenheiten im Team)
