# 09 – Assistent (Chatbot)

Seitenleiste, die beim Ausfüllen von Anträgen hilft (Beispiel: Bildungsurlaub).

## Funktionen

- Anliegen in eigenen Worten beschreiben; der Assistent schlägt Formularwerte vor
- Vom Assistenten ausgefüllte Felder sind gekennzeichnet, fehlende Pflichtangaben werden genannt
- Vorschläge für häufige Fragen
- Hinweis: Der Assistent trägt nur Vorschläge ein – gesendet wird erst durch die Person selbst
